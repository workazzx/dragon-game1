# dragon game

консольная игра на lua: бой с драконом

запуск: lua main.lua

## управление

1 удар (тратит 1 силу)
2 блок
3 перекат
4 зелье (+35 hp)
5 отдых (+2 силы)

## как выиграть

дракон перед ходом показывает чем атакует, но в 25% случаев подсказка врёт

дракон пригнулся (лапа):перекат
дракон набирает воздух (огонь):блок
дракон задрал голову (рёв):перекат или блок

когда сила кончилась, жми отдых ,зелье пей когда hp ниже 40, на 75 hp у дракона он звереет и бьёт сильнее
